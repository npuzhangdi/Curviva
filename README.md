# Curviva v0.0.0

科研绘图与数据分析工作台（Python + PySide6 + matplotlib + numpy）。参考 Origin 的常用功能分区，按 **P0 → P3** 逐级扩展完成；版本号按约定保持 `0.0.0` 不迭代。

> **扩展语言仅支持 Python**：公式列、自定义拟合模型、自动化脚本、插件全部是 Python 表达式 / `.py` 文件；不提供、也不计划支持 LabTalk、Origin C、R、MATLAB、JavaScript 等其它语言。

## 快速开始

**方式一：一键安装（推荐，首次使用）**

双击项目根目录的 **`first_run.bat`**，脚本会按三步引导完成环境准备：

| 步骤 | 内容 |
|---|---|
| **[1] 选择 Python** | 自动检测本机已安装的 Python（注册表 + `py` 启动器 + PATH，自动过滤微软商店别名与 msys/mingw 版本），按 `Python 版本 - 安装路径` 列出并让你输入编号选择；一个都没检测到时给出 python.org 官方下载地址与清华镜像 |
| **[2] 创建虚拟环境** | 用所选 Python 创建 `venv`；若已存在会询问是否删除重建 |
| **[3] 安装依赖** | 选择安装源（清华 TUNA / 阿里云 / 中科大 USTC / 官方 PyPI / 自定义），升级 pip 并安装 `requirements.txt`，最后把所选源写入 `venv\pip.ini` 供后续使用 |

**方式二：手动命令（不分发 venv，需自行创建）**

```bash
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
venv\Scripts\python.exe main.py
```

> 项目按「源码 + 脚本」方式分发，**不包含 800MB 的 venv 目录**。把整个文件夹拷到任何一台电脑后：双击 `first_run.bat`（选 Python → 选安装源，自动建 venv 并装依赖）→ 双击 `run.bat` 启动即可。`run.bat` 会检测 `venv` 与依赖是否齐全，缺失时提示先运行 `first_run.bat`。

启动后**无任何文档窗口**（工作区为空）——在左侧「项目管理器」的文件夹内容列表中双击工作簿 / 图片即可打开，或用「插入」菜单新建。

> 兼容性说明：Python 3.12 下 `main.py` 会在导入 PySide6 之前预加载 `matplotlib.dates`，以规避 PySide6 签名钩子与 six 虚拟模块的已知冲突，请勿删除该段代码。

## 功能一览

### 基础绘图（原有能力，全部保留）

| 类别 | 功能 |
|------|------|

| 曲线管理 | 逐曲线颜色/线型/线宽/标记/透明度/可见性/所属子图；新建、复制、删除、批量生成 |
| 多子图 | 行 × 列自由组合，曲线指定子图 |
| 数据 | CSV / TXT / DAT / TSV / ASC / XLSX / XLSM 打开（编码、分隔符、注释、列头自动识别）、Excel 多工作表点选导入、剪贴板粘贴、拖放打开、示例文件夹、数据预览 |
| 坐标轴 | 自动/手动范围、刻度模式（自动/个数/间隔）、固定小数位、线性/对数、反向 |

| 交互 | 滚轮缩放、双击还原、框选放大、平移、点选曲线、拖动图例/文本/数据点；停靠面板可浮动可拖动；工作区子窗口可最小化 |

| 窗口类型 | 内容 | 可最小化 / 显示隐藏 |
|---|---|---|
| 表格 | 一张工作表 = 一个子窗口，自带复制/粘贴/插入行列/生成曲线/插值/拟合/导出小工具栏 | ✅ |
| 图形 | 独立 Figure + 画布 + Origin 式鼠标编辑器，可有多个图形窗口，各有自己的尺寸与标注 | ✅ |

- 左侧项目树**双击**表格 / 图形 / 图片即在中间打开对应子窗口；也可从菜单、工具栏、数据面板、示例域、文件拖放打开。

### 独立示例文件夹 `examples/`

与源码分离的示例资源目录，菜单「文件 → 打开示例」按 `data / projects / scripts` 三个子目录自动生成，新增文件放进去即可，无需改界面代码。详见 `examples/README.md`。

| 子目录 | 内容 |
|--------|------|
| `data/` | 7 个示例：线性拟合 CSV、带 Origin 列头信息的双高斯峰 TXT、空白分隔多曲线 DAT、分组柱状 CSV、GBK 中文表头 TXT、三工作表 XLSX、含注释与缺失值的 TXT |

### 打开现有数据与复制粘贴

- **统一打开**：菜单「文件 / 数据 → 打开数据文件…」或 `Ctrl+Shift+O`，支持 `csv / txt / dat / tsv / asc / xy / xye / prn / out / xlsx / xlsm`；也可以把文件（含 `.cvproj`）**直接拖进主窗口**。
- **文本导入向导**：`文件 → 文本导入向导…`，可调文件编码（自动 / UTF-8 / GBK / Big5 / Latin-1）、分隔符（自动 / Tab / 逗号 / 分号 / 竖线 / 空白）、注释前缀（默认 `#,!,//,%`）、跳过行数、首行是否列名、表头后列头信息行数，并实时预览解析结果。
- **编码与科学数据细节**：自动识别 GBK 中文表头；`-- / NA / 空值` 转 `NaN` 且保持数值列；`Long Name / Units / Comments / F(x)=` 元数据行写进工作表的列头信息行；Excel 沿用「点选才导入」的工作表选择对话框。
- **两条粘贴路径**：①「从剪贴板新建工作表」（`Ctrl+Shift+V`）把 Excel / Origin / 文本里复制的整块数据生成新表格；② 在已有工作表里选中起始单元格按 `Ctrl+V`，数据写入当前表格并自动扩展行列，可勾选「粘贴首行作列名」。`Ctrl+C` 把选区复制为 TSV，另有「复制含列名」。

### Origin 风格工作表（工作区中的表格子窗口 / 多表工作簿）

- **表头**：`A(X) x`、`B(Y) y` 形式的列字母 + 列类型 + 列名；列类型可右键切换 X / Y / Z / yEr / xEr / L / D。
- **列头信息行**：长名称、单位、注释、公式 `F(x)=` 四行，直接编辑即可写回数据集并随 `.cvproj` 保存；公式行是**只支持 Python** 的表达式，输入后自动重算，公式列只读。
- **单元格**：即时编辑（数值/文本自动转换）、`Delete` 清空、行号显示；右键可插入/删除/重命名列、插入/删除/追加行、设置公式与列类型、生成曲线、调用插值/平滑/微分/积分/寻峰等数据处理、导出 CSV（可含列头信息）或导出全部工作簿 Excel。
- **多表标签**：`窗口管理 → 打开多表工作簿` 或工具栏按钮打开；多个数据集以标签页并列，可关闭、重命名、复制；状态栏显示行列数与选区均值/求和/范围。
- **打开方式**：项目树双击表格（打开独立表格子窗口）、数据面板「工作表」按钮、打开/拖入数据文件、打开示例数据都会自动打开对应窗口或标签页。

### 项目资源管理器与窗口管理（参考 Origin 的 Project Explorer）

- **项目 / 工作台双视图**：项目视图是可任意层级嵌套的树（项目根 → 文件夹 → 表格 / 图形 / 图片 → 数据列）；工作台视图按「数据表 / 图形 / 图形图片文档 / 最近操作」把全部资源扁平总览。
- **新建与管理**：新建项目（可命名）、新建文件夹、新建空白表格（可设名称/行数/列数，默认 X + Y + Y2…）、新建图形窗口、新建图片窗口、导入图片文件、重命名、复制、删除、拖拽归类、导入 CSV/Excel/剪贴板到指定文件夹、导出 CSV、一键生成曲线。
- **树上直接处理数据**：右键表格 →「数据处理」→ 插值 / 等间距重采样、SG 平滑、移动平均、归一化、基线扣除、微分、积分、FFT、寻峰、描述统计；参数由注册表自动生成表单，结果表格自动挂回源表格所在文件夹，可一键上图。与「数据分析」面板共用同一套引擎。
- **工作簿编辑**：双击表格在中间工作区打开 Origin 风格工作表，支持单元格即时编辑、复制粘贴、列头信息、新增列（可填 Python 公式）、删除/重命名列、增删行；公式列自动重算。
- **项目树随项目保存**：树结构写入 `.cvproj` 的 `workspace.tree`，图形/图片文档写入 `workspace.documents`；打开项目、撤销、重做都会完整还原文件夹、文档与归属；任何来源（导入 / 分析 / 拟合 / 脚本）新增的数据集都会自动补挂进树。
- **脚本 API**：`api.new_folder()` / `api.new_sheet()` / `api.rename_node()` / `api.workspace_outline()` / `api.active_folder()` / `api.open_data_file()` / `api.examples()` / `api.open_example()`，以及 `api.documents()` / `api.new_graph()` / `api.new_image()` / `api.graph_size()` / `api.annotate()` / `api.open_document()`，仍**仅支持 Python**。
- **窗口管理菜单**：3 个停靠窗口的显示开关、逐窗口设置对话框（显示 / 停靠位置 / 浮动 / 宽度 / 内部选项卡）、面板选项卡显示子菜单、上下文工具栏开关、全部工作区文档窗口列表（显示隐藏 / 激活 / 最小化 / 还原 / 关闭）、层叠平铺、全部显示 / 隐藏、保存当前布局 / 恢复默认布局。

### P0 项目与工作簿

- **`.cvproj` 项目文件**：完整配置 + 全部数据集（含公式列）+ **项目资源树** + 工作区文本（脚本、拟合摘要、分析日志），打开即完整还原图形与文件夹结构；菜单「文件」或「项目」面板，支持 `Ctrl+N/O/S`。
- **撤销 / 重做**：完整状态快照（不只是样式），导入数据、曲线增删、分析、拟合、样式变更都能回退；`Ctrl+Z / Ctrl+Y`，连续操作自动合并为一个撤销点。
- **样式主题**：默认湖蓝、期刊黑白、经典 Origin、高对比演示、柔和浅色，一键统一字体/配色/线宽/网格/边框。
- **Python 公式列**：`B * 2 + np.sin(x)` 这类表达式生成新列，源数据修改后自动重算；列引用支持 `A/B/C…`、`c1/c2/c3…`、合法列名、`col("任意列名")`，可用 `np`、`math`、`x`、`i`。
- **工作簿编辑**：双击单元格修改、导出当前数据集 CSV / 全部工作簿 Excel。

### P1 公式拟合

- **模型库**：线性、2–5 次多项式、单/双指数、对数、幂函数、Michaelis-Menten、Gaussian、Lorentzian、Boltzmann、正弦共 15 个；全部以 Python 表达式描述。
- **自定义模型**：写 `y0 + A * np.exp(-x / t)` 即自动推断参数 `y0/A/t`，与内置模型走同一拟合路径。
- **拟合设置**：参数初值表（留空自动估计）、无/统计/自定义误差列/自定义权重列五种权重、X 拟合区间、最大迭代、可选参数边界。
- **结果**：参数 ± 标准误、R² / 调整 R² / 约化 χ² / RMSE / RSS / AIC、残差、95% 置信带；一键把拟合曲线、置信带、残差散点加入图（普通数据集 + 曲线，随项目保存）；中文报告可复制或导出 `.md/.txt`。
- 引擎为纯 numpy 的 Levenberg–Marquardt 加权最小二乘（数值雅可比 + 阻尼迭代），**不依赖 scipy**。

### P2 数据处理与分析

注册表驱动，界面自动根据参数 schema 生成控件；结果统一生成新数据集，可直接「生成曲线」上图。

| 分类 | 操作 |
|------|------|
| 统计 | 描述统计（N/均值/SD/SE/方差/极值/分位数/IQR/偏度/峰度/CV/置信半宽，支持多列） |
| 平滑与变换 | 移动平均、Savitzky–Golay、中值滤波、高斯平滑、归一化（5 种）、基线扣除（常量/线性/多项式）、FFT 幅度谱 |
| 数学运算 | 一阶数值微分（支持非等间距 X）、梯形累积积分、线性插值、自然三次样条、等间距重采样 |
| 峰分析 | 局部极大寻峰、峰高阈值、突出度、最小间距、半高宽 FWHM、峰面积 |

### P3 模板 / 批处理 / 图层 / 扩展

- **图形模板 `.cvstyle`**：保存完整绘图配置，内置样式主题 + 用户模板（存于 `~/.curviva/templates`）；可应用、删除。
- **批处理**：选多个 CSV/XLSX 文件 → 自动选 X/Y 列 → 套用当前配置或指定模板 → 批量导出 PNG/SVG/PDF/EPS，带进度反馈；使用 Agg 后端，可脱离界面运行。
- **双 Y 轴图层**：每条曲线可选「左 Y 轴 / 右 Y 轴」，右轴独立范围、刻度、标签、对数、反向；图例自动合并左右图层。
- **误差棒**：曲线可指定 Y 误差列与端帽大小，折线/散点/点线/柱形均支持。
- **仅 Python 的脚本与插件**：工作台内置脚本编辑器（`api` 门面：数据集、曲线、分析、拟合、模板、导出、项目）、3 个示例脚本；插件为 `.py` 文件，声明 `NAME / DESCRIPTION / run(api)` 即被自动发现；附带「归一化全部数值列」「数据集概览报告」两个示例插件。
- 脚本层做 ast 导入白名单与危险调用过滤；**Python 沙箱不是系统级隔离，请只运行自己编写或可信来源的脚本**。

## 使用提示

1. 最左「项目管理」新建项目 / 文件夹 / 表格 / 图形 / 图片，或右键文件夹导入 CSV/Excel → 双击表格在中间工作区打开 → 工具栏「数据画图」或右键「生成曲线」；顶部工具栏与右侧属性页都可实时调样式。
2. 「数据分析」选操作、填参数 → 执行 → 结果自动成为新数据集，点「结果生成曲线」即可叠加到图上。
3. 「曲线拟合」选数据集/X/Y 与模型 → 执行 → 查看参数与 R² → 「拟合曲线上图」「残差上图」；自定义表达式里除 `x` 外的自由变量就是待拟合参数。
4. 双 Y 轴：右侧「曲线」把某条曲线的「绘制在」改为「右 Y 轴」，再到「坐标轴」设置右轴标签与范围。
5. 「项目」面板管理 `.cvproj`、撤销重做、样式主题、公式列；「工作台」管理模板、批处理、脚本与插件。
6. 需要导出全部原始点：先在「布局标题」关闭「智能抽稀」再导出；EPS 不支持透明度。
7. 想对某张表格做插值：在项目树右键该表格 →「数据处理 → 插值 / 等间距重采样」→ 设置目标点数与线性/三次样条 → 执行，结果表格会出现在同一文件夹，点「结果生成曲线」即可叠加。
8. 想精简界面：菜单「窗口管理」逐窗口关掉不需要的侧栏、隐藏上下文工具栏，或在「工作区文档窗口」里隐藏/最小化暂时不用的表格与图形；「窗口布局设置…」可单独调整每个停靠窗口的位置、浮动与宽度，布局会自动保存。
9. 打开示例：菜单「文件 → 打开示例」可一键载入示例数据（自动弹出工作表）、示例项目或 Python 示例脚本；也可选「浏览 examples 文件夹」。
10. 打开自己的数据：把 CSV/TXT/DAT/XLSX 拖进主窗口，或用「打开数据文件」；中文 GBK 文件、带注释/缺失值的文本会自动识别，需要精细控制时用「文本导入向导」。
11. 从 Excel 复制一块区域 → 在 Curviva 工作表点起始单元格按 `Ctrl+V`（可勾「粘贴首行作列名」）；反向 `Ctrl+C` 可把选区粘回 Excel。
12. 图上直接改图：激活图形窗口 → 顶部工具栏选「选择 / 文本 / 图例 / 数据点 / 平移 / 框选放大」→ 在图上单击、拖动或双击；右键有完整编辑菜单。工具栏还能直接改图形宽高、单位与 DPI 并导出。
13. 选中不同对象时顶部工具栏会自动变形：激活表格看「数据画图 / 拟合 / 数据处理」，激活图形看「编辑工具 / 尺寸」，激活图片看「缩放 / 显示尺寸」。

## 已知限制

- `.xls` 旧格式 Excel 暂不支持（仅 `.xlsx/.xlsm`），打开时会提示先另存为 `.xlsx`。
- 工作表单表最多显示前 2000 行（数据本身不截断，导出与分析仍使用全量数据）；编辑单元格后公式列已重算，切到其它标签或点「刷新」可看到最新值。
- 数据文件里的 `F(x)=` 行会作为公式提示显示，不会自动执行非 Python 语法；工作表公式行写入的才是可执行的 Python 表达式。
- 95% 置信带以「上限/下限两条虚线」呈现，未使用 `fill_between` 填充。
- 绘图区白色留白来自 figure 英寸尺寸与窗口尺寸未联动，导出图形不受影响；每个图形窗口按自己的文档尺寸导出。
- 多个图形窗口共享同一份 `PlotConfig`（配置驱动架构），因此曲线与坐标轴样式是全局的；每个窗口独立的是尺寸 / DPI / 文本标注 / 图例位置 / 选中曲线。
- 图片窗口只做查看、缩放与另存，暂不提供像素级编辑；SVG 由 Qt 渲染，复杂滤镜可能显示差异。
- 数据点拖拽按 X 值就近匹配回写工作表行，若 X 列存在重复值会写回第一个匹配行。
- 未实现：全局拟合 / 多峰批量拟合、曲面拟合、Rank Models、ANOVA 等高级统计、Origin 项目文件互操作；脚本不支持 Python 之外的任何语言。
