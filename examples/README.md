# Curviva 示例文件夹（examples）

这是一个**独立的示例资源文件夹**，与软件源码分离：把这里的文件换成自己的数据即可复用同样的流程。软件菜单 **「文件 → 打开示例」** 会自动列出本文件夹 `data/ / projects/ / scripts/` 下的全部示例；新增文件只要放进对应子目录，菜单会自动出现，无需改代码。

```
examples/
├── controller.py       ★ 示例域控制调用文件（列出 / 打开示例）
├── README.md           本说明
├── data/               示例数据：CSV / TXT / DAT / XLSX
├── projects/           示例项目：.cvproj
└── scripts/            仅 Python 的脚本与插件示例
```

## data/ — 示例数据

| 文件 | 格式与要点 | 建议玩法 |
|------|-----------|----------|
| `01_线性拟合.csv` | UTF-8 CSV，表头 `x,y`，30 组带噪声线性数据 | 打开 → 工作表查看 → 曲线拟合「线性」→ 拟合曲线上图 |
| `02_高斯峰.txt` | Tab 分隔；`#` 注释行；Origin 风格 `Long Name / Units / Comments` 列头行 | 打开时在「文本导入选项」里看解析预览；列头信息会进入工作表的长名称/单位/注释行；适合寻峰、Gaussian 拟合 |
| `03_多曲线.dat` | 空白分隔、无表头提示，4 列数值 | 打开 → 右键表格「生成曲线」或「批量生成曲线」一次画 3 条 |
| `04_分组柱状.csv` | 文本类别列 + 对照组/实验组数值 | 生成两条柱形曲线，比较分组柱 |
| `05_GBK中文表头.txt` | **GBK 编码**、分号分隔、中文列名与 ℃ 单位 | 直接打开，验证编码自动识别（不需手动选 GBK） |
| `06_多表格工作簿.xlsx` | 3 个工作表（线性数据 / 高斯峰 / 分组柱状），其中「高斯峰」含 Units 元数据行 | 打开 → 工作表选择对话框点选要导入的表（不选中不导入） |
| `07_注释与缺失值.txt` | `!` 注释行、空白分隔、缺失值 `--` | 直接打开，`--` 自动变成 NaN，数值列仍保持数值类型 |

也可以直接把任意 `csv / txt / dat / tsv / asc / xy / xlsx / xlsm` **拖到主窗口**打开；文本文件可在「文本导入选项」里指定编码、分隔符、注释前缀、跳过行数、首行是否表头、元数据行数。

## projects/ — 示例项目

- `示例项目.cvproj`：包含「示例数据」文件夹、2 张数据表、2 条曲线、标题 / 轴标签 / 网格等完整样式。菜单「文件 → 打开项目」或「打开示例 → 示例项目」即可完整还原，用来检查项目保存 / 打开 / 撤销重做。

## scripts/ — 仅 Python 的扩展示例

Curviva 的扩展**只支持 Python**，没有 LabTalk、Origin C 等其它语言。

| 文件 | 用法 |
|------|------|
| `01_快速上手.py` | 菜单「打开示例」直接载入「工作台 → Python 脚本」编辑器，点运行 |
| `02_批量插值.py` | 载入脚本编辑器；先导入几张数据表，再运行，会批量做插值重采样 |
| `03_示例插件.py` | 复制到 `~/.curviva/plugins/` 后，在「工作台 → Python 插件」中自动出现 |

脚本通过 `api` 门面操作软件，可用 `api.datasets()` / `api.columns()` / `api.values()` / `api.add_curve()` / `api.analyze()` / `api.fit()` / `api.export()` / `api.new_folder()` / `api.new_sheet()` / `api.open_data_file()` 等。

## 工作表（Origin 风格）

打开任意示例数据后会自动弹出底部「工作表」窗口：

- 列标 `A(X) / B(Y) / C(Y)…`，列类型可右键切换（X / Y / Z / yEr / L / D）；
- 列头信息行：**长名称 / 单位 / 注释 / 公式 F(x)=**，可直接编辑；公式行写 Python 表达式即自动重算；
- 单元格即时编辑；`Ctrl+C` 复制选区为 TSV，`Ctrl+V` 把 Excel / 文本数据粘贴进来并自动扩展行列；
- 右键可插入/删除/重命名列、增删行、清空、导出 CSV/Excel、生成曲线、调用插值等数据处理；
- 多张表以标签页并列，标签可关闭 / 重命名 / 复制；窗口可在「窗口管理」里单独显示、停靠、浮动、调宽。
